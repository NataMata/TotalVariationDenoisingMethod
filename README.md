# Uklanjanje šuma iz slika pomoću totalne varijacije

## O projektu
## Teorijska osnova
Prisustvo šuma na slikama je neizbežna pojava koja nastaje kao posledica prirode svetlosti i načina na koji je slika napravljena. Šum može značajno degradirati kvalitet slike i otežati njenu analizu i obradu. Zbog toga je neophodno primeniti metode za uklanjanje šuma.
